    Typing and AI activity

    On Windows, Clawd uses a short-lived local signal to show its typing pose while you use the keyboard. It does not store key values or typed text, and keyboard activity is never sent to Ollama. The thinking pose appears while an AI reply and its actions are running.

    Local file search

    Clawd searches filenames only in folders you enable. It does not read file contents. Search stays on this computer; your message goes to Ollama Cloud so it can understand what you asked.

    Chats stay in memory and are not saved. Tasks and reminders are stored locally. Your API key is kept in the operating system credential store, not in browser storage.
